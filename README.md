# 🔌 CCNA Module 2 – Switching, Routing & Wireless Essentials (SRWE)

Welcome to my **CCNA Module 2 (SRWE)** repository.  
This repository contains Packet Tracer labs, configurations, and learning activities related to the **Switching, Routing & Wireless Essentials** module of the CCNA curriculum.

---

## 🚀 About This Module

Switching, Routing & Wireless Essentials (SRWE) focuses on the core concepts of modern networking, including switching operations, routing fundamentals, VLANs, and wireless network configurations.

This module covers:

- 🔹 Basic switch and router configuration  
- 🔹 VLANs and trunking  
- 🔹 Inter-VLAN routing  
- 🔹 Static routing  
- 🔹 Wireless LAN concepts  
- 🔹 WLAN configuration and security  
- 🔹 STP and EtherChannel fundamentals  
- 🔹 DHCP configuration  
- 🔹 Network troubleshooting techniques
